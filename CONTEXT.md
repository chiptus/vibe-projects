# YAYOG Tracker

A workout log for the programs in the book *You Are Your Own Gym*, and the tests that say which program a person should follow.

## Language

**Level**:
The book's ability tier a person trains at: Basic, 1st Class, Master Class or Chief Class.
_Avoid_: Difficulty, tier, grade

**Program**:
The 10-week plan for one Level. Never use it as a synonym for Level.
_Avoid_: Routine, plan, course

**Block**:
A run of weeks within a Program that shares a training method: Muscular Endurance, Strength, Power, Undulating.
_Avoid_: Phase, cycle

**Workout type**:
The shape of a day's session: ladder, interval, superset, tabata or stappers.
_Avoid_: Format, style

**Level test**:
The four-part check a person must pass to start a Level above Basic. Basic has none.
_Avoid_: Assessment, exam, benchmark

**Minimum**:
The required result for one category (Push, Pull, Legs, Core) in a Level test. A Level test is passed only when all four Minimums are met.
_Avoid_: Target, threshold

**Highest passed**:
The top Level whose Level test has a passing result. Passing a Level also counts as passing every Level below it.
_Avoid_: Current level, rank

**Recommendation**:
The Level the app suggests, equal to the Highest passed. The person decides whether to switch.
_Avoid_: Placement, assignment
