# Level tests recommend, never switch, and reveal one test at a time

Test results are stored as the person's actual numbers with a date. Pass/fail, Highest passed, unlocked Levels and the next test are derived from them, never stored. The app only recommends a Level; switching is always the user's confirmed choice. Only the test for the Level above Highest passed is shown, and the Level picker lists only unlocked Levels, so no advanced test or Program is visible before it is earned. Chosen deliberately to avoid pushing people toward programs they are not ready for.
