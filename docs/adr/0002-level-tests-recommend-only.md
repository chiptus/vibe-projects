# Level tests recommend, never switch, and reveal one test at a time

Test results are stored as the person's actual numbers with a date. Pass/fail, Highest passed and the next test are derived from them, never stored. The app only recommends a Level; switching is always the user's confirmed choice. Only the test for the Level above Highest passed is shown, so no advanced test is visible before it is earned. Chosen deliberately to avoid pushing people toward Levels they are not ready for.

All four Programs stay selectable at any time: tests advise, they do not gate. An earlier version hid Levels until their test was passed; that was reversed so people can follow any Program they choose.
