# Sideload the watch app first; publish to the Connect IQ Store later

For now the watch app is compiled by the owner with the Connect IQ SDK and copied to the watch over USB. No developer account or store review is needed, and nothing in the design prevents publishing later. Open: how Garmin treats a sideloaded app that is later published with the same app ID is unverified; expect to uninstall and reinstall from the store. The code is written without a simulator in our environment, so the owner tests on the device.
