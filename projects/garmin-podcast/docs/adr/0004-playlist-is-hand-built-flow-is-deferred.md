# The Playlist is hand-built; playrun's automatic "flow" is deferred

In playrun, a flow auto-downloads new episodes from added podcasts and a playlist is a list the person builds. The owner only uses the playlist, so v1 has the Library (saved Podcasts), the Playlist (Episodes the person picks), and a Storage budget. When a Playlist exceeds the budget, the oldest Episodes by publish date are dropped from the Sync. "Flow" stays out of the language until it is built, so it is not reused for the Playlist.
